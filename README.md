# [potato](https://potato-potato.vercel.app/)

동호회 운동 기록과 회비 공지를 간편하게 할 수 있도록 도와주는 웹 서비스입니다.

기존에는 구글 드라이브의 엑셀 파일로 출석, 할인 내역, 회원 정보를 관리하고, 회비 공지에 필요한 내용을 직접 캡처해 공유했습니다.

운동이 끝날 때마다 파일을 열어 기록을 정리하고, 공지용 이미지를 별도로 준비하는 과정이 번거로웠습니다.

이 과정을 모바일에서 간편하게 처리하기 위해, 운동 현장에서 휴대폰으로 출석과 할인 내역을 기록하고 회원 관리부터 회비 공지용 이미지 생성까지 할 수 있는 서비스를 만들었습니다.


## 개발 의도

- 실제 동호회 운영에 필요한 기능을 빠르게 구현하고 배포한다.
- AI를 활용하되, 파일 구조와 코드 작성 규칙을 정해 일관성을 유지한다.
- 별도 백엔드 서버 없이 Next.js의 서버 기능과 Supabase를 활용한다.

## 작업 방식

설계와 디자인 시스템 구축부터 페이지 구현, DB 연결, 로그인 및 첫 배포까지 약 3일간 진행했습니다.

구조와 구현 방향은 직접 결정하고, AI에는 문서화한 규칙을 바탕으로 구현과 수정을 맡겼습니다. 결과를 검토하면서 요구사항과 규칙을 구체화했습니다.

## 기술 스택

| 기술 | 선택 이유 |
| --- | --- |
| React · TypeScript | 가장 익숙한 기술로, 구현 부담을 줄이고 필요한 기능을 빠르게 개발하기 위해 선택 |
| Next.js | 서버 렌더링과 Server Actions를 활용해 별도 백엔드 서버 없이 구현 |
| Tailwind CSS | styled-components의 유지보수 모드 전환을 계기로, 유틸리티 클래스 기반의 스타일링 방식을 경험해보기 위해 선택 |
| Supabase | PostgreSQL 기반 데이터 저장과 인증, RLS 접근 제어를 활용하고 무료 플랜으로 시작 |
| Vercel | Next.js 서버 기능을 간편하게 배포할 수 있고, Git 연동과 무료 플랜을 제공해 선택 |
| npm | 기존 Yarn Berry 사용 중 겪었던 패키지 호환성 문제를 고려해 선택 |

## 주요 기능

### 날짜별 출석 및 할인 기록

- 운동 날짜를 선택하고 참석한 회원과 할인 항목별 대상 회원을 체크합니다.
- 조끼·공 운반, 구장 예약 등 회비 할인에 해당하는 활동을 출석과 함께 기록합니다.
- 저장한 날짜의 기록을 다시 조회하고 수정하거나 삭제할 수 있습니다.

<img src="./docs/images/운동%20기록.jpg" width="320" alt="날짜별 출석 및 할인 기록 화면" />

### 회비 유형 관리

- 회원 유형별 기본 회비와 할인 적용 여부를 설정합니다. 고정 회비 유형은 할인 내역과 관계없이 정해진 회비를 적용합니다.

<img src="./docs/images/회원유형관리.jpg" width="320" alt="회원 유형별 회비 및 할인 적용 설정 화면" />

### 회원 관리

- 회원을 등록하고 회원 유형을 설정합니다.

<img src="./docs/images/회원목록관리.jpg" width="320" alt="회원 목록 관리 화면" />

### 할인 유형 관리

- 동호회 운영에 필요한 할인 항목의 이름과 금액을 추가·수정·삭제합니다.
- 등록한 항목을 운동 기록 화면에서 선택해 회원별 할인 내역을 남깁니다.

<img src="./docs/images/회비%20할인%20유형%20관리.jpg" width="320" alt="할인 유형과 금액 관리 화면" />

### 월별 회비 공지 이미지 생성

- 회비를 안내할 월을 선택하면 전월 운동 기록과 회원 유형별 기본 회비를 바탕으로 납부 금액을 계산합니다.
- 회원별 출석, 할인 내역, 납부 금액과 합계를 회비 납부표 이미지로 생성합니다.
- 파일 공유를 지원하는 모바일 환경에서는 공유 메뉴를 이용하고, 그 외 환경에서는 PNG 파일로 다운로드할 수 있습니다.
- 기존 회비 공지 이미지와 비슷하게 구현했으나, 추후 좀 더 보기 좋게 변경할 예정입니다.a

<img src="./docs/images/2026-11-회비-납부표.png" alt="월별 출석과 할인 내역을 반영한 회비 납부표" />

## DB 스키마
- 기본 로그인 기능은 supabase의 auth 기능을 활용하였습니다.
- 운영진의 종류를 최고운영진, 실무운영진으로 역할을 나누고, admin 테이블을 만들어 role에 권한을 저장하여 권한에 따라 화면 분기처리를 하였습니다.
- 운동 기록은 최신 상태가 과거의 상태와 섞이지 않도록 기록 당시의 출석, 할인 내역을 스냅샷 형식으로 저장합니다.
